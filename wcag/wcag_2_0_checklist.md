# WCAG 2.0 Basic Manual Checklist

Portfolio-level checklist for desktop/mobile exploratory accessibility testing.

- Keyboard: all interactive elements reachable without mouse.
- Focus: visible keyboard focus and logical focus order.
- Labels: form inputs have meaningful labels/instructions.
- Errors: validation errors identify the field/problem in text, not color alone.
- Contrast: text and interactive state contrast is sufficient for normal use.
- Zoom: content remains usable at 200% zoom without loss of essential information.
- Mobile: controls remain reachable and readable on narrow viewport.
- Headings: page structure uses meaningful heading order.
- Links/buttons: purpose is understandable from accessible name/context.
- Status messages: important success/error state is announced or clearly exposed to assistive technology.

This is a basic manual screening checklist, not a formal accessibility audit or certification.
